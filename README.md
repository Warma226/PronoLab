# Prono Lab

Pronostics foot du week-end (Premier League, Liga, Serie A, Bundesliga, Ligue 1), avec comptes et abonnements.

- `data/matches.json` : matchs et statistiques, mis à jour chaque semaine.
- `config.js` : configuration Firebase, numéro administrateur et formules.
- `firestore.rules` : règles de sécurité à coller dans Firebase.
